## What is CraftySkins?

CraftySkins gives Minecraft players a browser workspace for designing custom skins. The interface is intended for building and adjusting skin layouts without installing a conventional desktop program.

Because the project is packaged as a static application, it can be opened in a current browser or published through a basic static hosting service. It provides a focused place to begin and refine Minecraft skin designs.
